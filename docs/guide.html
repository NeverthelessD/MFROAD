MFROAD

My Finance ROAD · 국내주식과 코인을 한 화면에서, 지금 가격으로 · 사용 가이드

1설치하고 열기

  1. 받은 zip 을 풀고 MFROAD.app 을 응용 프로그램 폴더로 옮겨요. (그래야 새 버전을 알아서 받아요)
  2. 처음 열 때 경고가 뜨면 시스템 설정 › 개인정보 보호 및 보안 아래쪽의 그래도 열기를 눌러요.
  3. 창을 닫아도 MFROAD 는 Dock 에 남아요. 완전히 끄려면 ⌘Q

2종목 넣기

  1. 오른쪽 위 + 종목 추가 → 국내주식 또는 코인
  2. 이름 · 코드 · 초성으로 찾아요. 예) 삼성전자, 005930, ㅅㅅㅈㅈ, BTC
  3. 어느 증권사 계좌 / 거래소에 있는지 고르고, 보유 수량과 평균 매수가를 넣으면 끝!
  4. 넣은 기록을 고치거나 지우려면 그 줄을 눌러요.

3같은 종목, 여러 계좌

나무증권 · 한국투자처럼 계좌마다 따로 넣으면 합쳐서 보여 주고, 줄을 누르면 계좌별로 펼쳐져요.
▾ 삼성전자 계좌 2개160주평단 63,000+14.76%
나무증권 자동120주61,500+17.56%
한국투자40주67,500+7.11%
같은 계좌에 같은 종목을 더 넣으면 수량을 더하고 평균 단가를 다시 계산해요.

4나무증권 연결 (선택)

  1. nhplug.com 에서 API 사용신청 → App Key · App Secret 받기
  2. MFROAD 설정 → 두 키를 붙여 넣고 저장하고 연결
  3. 국내주식이 실시간 시세로 바뀌고, 나무증권 계좌의 주식은 자동으로 불러와요.
🔒 키는 이 Mac 의 키체인에만 저장돼요. MFROAD 는 조회만 하고 주문은 하지 않아요.

화면 읽는 법

  • 빨강 ▲ + 오르거나 이익 · 파랑 ▼ − 내리거나 손해
  • 맨 위 총 자산 · 총 손익 · 오늘(전일 대비) · 오늘 그래프(1분마다 한 점)
  • 값이 바뀐 현재가는 잠깐 색이 깜빡여요. 오른쪽 위에 마지막으로 받은 시각이 보여요.

설정에서 바꿀 수 있는 것

  • 시세 갱신: 실시간(권장) · 5초 · 30초 · 1분
  • 화면: 맥 설정 따름 · 라이트 · 다크
  • 계좌 이름 바꾸기 · 지우기, 업데이트 확인 · 자동 업데이트

꼭 알아 두세요

  • 나무증권을 연결하기 전에는 국내주식이 전일 종가로 보여요. 코인은 업비트 시세로 늘 바로 보여요.
  • 장이 닫힌 시간(평일 저녁 · 주말)에는 마지막 가격을 보여 줘요. 시세와 손익은 참고용이에요.
  • 나무증권은 접근 토큰을 새로 받을 때 알림을 보낼 수 있어요. MFROAD 는 토큰을 저장해 두고 하루에 한 번 정도만 새로 받아요.
  • App Key · App Secret 은 다른 사람에게 보내지 마세요. 새 버전이 나오면 앱이 알아서 받아요.
